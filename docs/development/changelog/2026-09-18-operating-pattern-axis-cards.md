# Operating pattern axis cards

Replaced the catalogue detail panel's four plain rows with token-colored cards. Each shows the axis, code letter, a pole-specific geometric illustration, a short HU/EN explanation, and both poles with the current one highlighted. All eight poles have distinct artwork and copy. These are categorical illustrations, not score charts; report measurement bars are unchanged.

Uses the shared axis labels and existing public pattern code. Responsive cards stack on narrow screens, with the existing character illustration and description retained. Validated all catalogue selections through the four existing client tests, HU/EN browser views, and layouts at 1280, 768, 390 and 320px without horizontal overflow. TypeScript and targeted ESLint pass.

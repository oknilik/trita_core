A napi trita-riport két javaslatának megvalósítása (feature-ideas #1

## Bizalmi háló MVP (feature-ideas #1 → megvalósítva)

- **Séma**: `TrustObservation` (teamId, campaignId, aboutUserId,
  raterUserId, answers Json; unique kampány+about+rater) — a
  TeamRoleObservation tükör-mintája, init-migráció szinkronban.
- **Instrumentum**: `lib/trust-network.ts` — 5 kérdés/csapattárs HU/EN
  (szakmai bizalom 1–5, segítségkérés-gyakoriság 1–3, nyílt kommunikáció
  1–5, döntésbe bevonás 1–3, együttműködés-minőség 1–3), validátor,
  irányított 0–100 score.
- **Háló-logika** (tiszta lib): irányítatlan pár-él = irányok átlaga
  (mutual flag), edge-típusok: strong_trust ≥75 / moderate ≥55 /
  weak_trust ≥35 / disconnected. Csomópont-statisztika: befelé irányuló
  bizalom átlaga CSAK n ≥ 3 értékelőtől (TRUST_MIN_RATERS, pulse-minta);
  hub = legtöbb erős él (min. 2); beágyazatlan tag = 2+ mért él, egyik
  sem éri el a moderate-et. Lefedettség a lehetséges párok arányában.
- **Lépés-motor**: CAMPAIGN_STEP_ORDER = … → TEAM_ROLE_360 → **TRUST_360**
  → PSYCH_SAFETY; label + link (/assessment/trust); wizard-kártya +
  org campaigns API enum; csapat-kötelezettség a TRUST_360-ra is.
- **API**: `GET /api/trust/peers` (értékelendő tagok + haladás),
  `POST /api/trust/peers/submit` (batch-upsert tranzakcióban, lefedettség
  → idempotens léptető) — a team-roles/peers guard-mintáival
  (STEP_LOCKED, SELF_RATING_FORBIDDEN, NOT_A_TEAM_MEMBER).
- **Kitöltő UI**: `/assessment/trust` — kártya-carousel csapattársanként,
  5 kérdés (1–5 gombsor / 3-fokú opciók), személyenkénti azonnali mentés,
  consent-szöveg az intro-n (pár-szintű összevont kép, vezető/tanácsadó,
  n ≥ 3 aggregátum-küszöb).
- **Dinamika-térkép**: a mért trust-él felülírja a profil-alapú becslést
  (`team-stats.ts` mergeTrustEdges; strong→aligned, moderate→
  complementary, weak/disconnected→friction; confidence: mutual 100 /
  egyirányú 50; mért pár profil-él nélkül is felkerül). A DynamicsMap
  „mért" badge-et és forrás-lábjegyzetet kapott (mért X/Y kapcsolat vs.
  becslés) — a becslés fallbackként megmarad.
- **Értesítés-fix mellékesen**: a MEASUREMENT_STEP_OPENED linkek mostantól
  a kanonikus CAMPAIGN_STEP_LINKS-ből jönnek (a TEAM_ROLE_360 link eddig
  /dashboard-ra esett); a mérés-idővonal TYPE_LABELS-e is teljes.
- **Tesztek**: `tests/unit/team/trust-network.test.ts` — validátor,
  scoring, él-átlagolás, küszöbök, hub/izolált, lefedettség, lépés-sorrend.

## HBR „4 csapda" → vezetői akciókártyák a riportban

- **`lib/psych-safety.ts`**: `PSYCH_SAFETY_LEADER_TRAPS` — 4 kártya
  (érzelmi reaktivitás, bizonyosság-csapda, szó–tett rés, önigazolás),
  mindegyik csapda-leírás + ellenszer HU/EN + pulse-terület térkép;
  `leaderTrapsForWeakItems` helper. Keret-forrás: Brady–Kliman–Smith:
  *4 Hidden Traps of Team Dynamics*, HBR 2026/07 — saját megfogalmazású
  adaptáció, a riportban forrás-lábjegyzettel.
- **TeamReportView**: „Vezetői akciókártyák" blokk a gyenge pulse-területek
  után; **team-report.ts**: a leadershipGuide prefill max 2 csapda-sorral
  bővül.
- **`docs/pilot/riport-ertelmezesi-sablonok.md`**: 4/b Önkép vs. csapatkép
  peer-debrief szekció (a team-role-360-plan 8. pontjának nyitott tétele)
  + 5/b csapda-keret táblázat és debrief-használat.
- **feature-ideas.md**: #1 → MVP megvalósítva; #2 → megvalósult
  (2026-07-20, túlteljesítve a peer-réteggel).

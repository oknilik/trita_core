# Changelog — 2026-04-01

## UI Design System egységesítés

Teljes UI primitív rendszer bevezetése a szétszórt, ismétlődő UI patternek helyett.

**Új primitívek:**
- `Button` — egységes gomb komponens (primary/secondary/danger/ghost)
- `Card` — panel/kártya (spacing variánsokkal)
- `SectionEyebrow` / `SectionHeading` — szekció fejlécek
- `StatusChip` — státusz badge-ek (success/warning/neutral/danger)
- `InlineBanner` / `EmptyState` — értesítések és üres állapotok
- Form primitívek: `Field`, `FieldLabel`, `FieldInput`, `FieldTextarea`
- `SurfaceHero` — hero szekció self/team/org variánsokkal

**Token rendszer:**
- Szemantikus CSS változók bevezetése (`--color-text-primary`, `--color-surface-canvas`, stb.)
- Állapot tokenek: hover, disabled, focus-ring
- Surface accent tokenek: self/team/org
- Motion, radius, shadow, spacing skálák

**Migrációk:**
- CTA gombok → `Button` primitív
- Panel/kártya receptek → `Card` primitív
- Szekció fejlécek → `SectionEyebrow` / `SectionHeading`
- Form inputok → Field primitívek
- Hex színek → CSS variable tokenek (top ismétlődő színek)

**Avatar policy:**
- Centralizált avatar rendszer (`getAvatarGradient`, `getAvatarMonogram`)
- Doodle avatar assets leválasztása az observe flow-ról

**Infrastruktúra:**
- `cn()` helper bevezetése (class name merger)
- Automatizált UI debt audit script
- UI audit guardrail CI lépés
- Contributor guide és migration playbook

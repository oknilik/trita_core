## Pszichológiai biztonság pulse — mérés + kommunikáció (negyedik kör)

Döntés (user): szeptember 1-re kész; kommunikáció program-elemként +
pilot-újdonságként; teljes anonimitás, min. 3 fő küszöb.

### Instrumentum
- **`src/lib/psych-safety.ts`** (új, kliens-safe, prisma-mentes): 8 saját
  megfogalmazású item HU/EN az Edmondson-konstruktum tartalmi területeire
  (hibázás, segítségkérés, eltérő vélemény, kényes témák, kockázat,
  aláásás, megbecsülés, egyet-nem-értés), 3 fordított itemmel. Forrás- és
  anonimitás-dokumentáció a fájl fejlécében (Edmondson 1999, ASQ 44(2)).
- Pontozás: fordított itemek normalizálása, 0–100 index, itemenkénti
  átlag, válaszadók közti szórás, sávok (low <55 / mid / high ≥75).
- **Aggregálás csak ≥3 válasznál** — alatta null (anonimitás-küszöb).

### Séma + API
- **`PsychSafetyResponse`** modell: SZÁNDÉKOSAN user-referencia nélkül,
  véletlen UUID id, nap pontosságúra csonkolt `submittedOn`.
  `CampaignParticipant.completedAt` (új mező) követi a kitöltöttség
  TÉNYÉT, értékek nélkül. Init-migráció SQL kézzel szinkronizálva
  (a DB-reset runbook változatlan).
- **POST `/api/psych-safety/submit`**: résztvevő-ellenőrzés, ACTIVE +
  PSYCH_SAFETY guard, dupla beküldés 409, tranzakcióban anonim válasz +
  completedAt.
- Kampány-létrehozás: `PSYCH_SAFETY` típus engedélyezve, csapat kötelező
  (mint a szerep-körnél).

### UI
- **CampaignWizard**: a „Hamarosan" kártya élesítve (meta: „8 állítás ·
  ~2 perc / fő · névtelen"), csapat-célzás a szerep-kör radio-mintájával
  (`isTeamLocked`).
- **`/assessment/psych-safety`** (új oldal + kliens): a self-kitöltés
  vizuális nyelvén (QuestionCard + ProgressBar, egyszerre egy állítás),
  anonimitás-ígéret az intro-n és a kitöltés alatt is; NINCS piszkozat-
  mentés (anonimitás — localStorage-nyom sem marad).
- **Kampány-részletező**: PSYCH_SAFETY ágon biztonság-index blokk
  (0–100 + sáv + szórás + állításonkénti sávok), küszöb alatti állapotnál
  magyarázó szöveg; self/observer statok és per-fő chipek elrejtve
  (társas nyomás ellen csak darabszám látszik).
- **Team-oldal**: kitöltés-felhívó banner a tagoknak aktív, még ki nem
  töltött pulse-nál (→ /assessment/psych-safety).

### Kommunikáció (három mérési réteg)
- **pricing.teamBody + teamHow1 + faqA4**: személyiség + csapatszerep-
  térkép + névtelen biztonság-pulse a program leírásában.
- **Landing team-mód kártyák**: „Konfliktus-érzékelés" → „Pszichológiai
  biztonság" kártya; a dinamika-kártya a szerepeket is említi.
- **Pilot-oldal**: hero a három réteggel; benefit5 „Korai hozzáférés az
  új mérésekhez" (a be nem váltott tension-heatmap-AI ígéretek helyett a
  valós pulse + szerep-kör); step1 ~15 perc → ~10 perc (60 itemes forma).

### Verifikáció

  0/50/100 határesetek, szórás, sávok) — a sandboxban vitest natív binding

- tsc: lásd a kör végi kapu.

Hátralévő (user gépén): DB-reset runbook (a migráció bővült!), majd kézi

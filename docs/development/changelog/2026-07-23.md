## Statikus marketing-réteg: root layout szétvágás route group-okra

- **Motiváció**: a root layout `force-dynamic` + `auth()` + 4–6 Prisma-query
  minden requesten → az összes oldal (marketing is) dinamikus volt; SEO- és
  TTFB-büntetés a publikus oldalakon.
- **Root layout** lecsupaszítva: fontok, ClerkProvider, LocaleProvider,
  ToastProvider, statikus metadata (DEFAULT_LOCALE) — se auth, se DB, se
  cookie/header olvasás.
- **`(app)/layout.tsx`**: a korábbi heavy shell (auth + journey + org-
  kontextus + NavHeaderUI + HelpWidget) ide költözött, explicit
  `force-dynamic`-kal. Ide tartozik: dashboard, profile, assessment*,
  assessment-layers, org*, team*, manager, admin, hiring, onboarding, join*,
  advisory, observe, share, apply, try.
- **`(marketing)/layout.tsx`**: statikus shell (NavBar kliens-oldali Clerk
  auth-state-tel, Footer, HelpWidget public). Ide tartozik: `/`, pricing,
  pilot, privacy, contact, patterns, founding, blog, blog/[slug].
- **Landing**: `auth()`-redirect a proxy-ba került (`/` + userId → journey
  handoff); a `?mode=` paramétert az új kliens `LandingContent`
  (useSearchParams + Suspense) kezeli.
- **Cookie-mentesítés**: pricing/privacy/contact/blog-lista tartalma kliens
  komponensbe (`useLocale`), metadata statikus HU; az érvénytelen hreflang
  (`getLanguageAlternates` — minden nyelv ugyanarra az URL-re) lekerült a
  marketing-oldalakról.
- **Blog/[slug]**: a keret a cikk nyelvén renderel (`post.locale`), a
  nyelvváltás fordítás-párra ugrása kliens-oldali (`TranslationRedirect`).
- **Eredmény** (`pnpm build`): `/`, pricing, pilot, privacy, contact,
  patterns, founding, blog, sign-in/up = ○ statikus; blog/[slug] = ● SSG
  (14 poszt). App-oldalak maradtak ƒ. `@/app/admin|assessment|hiring|observe`
  importok átírva `@/app/(app)/…`-ra (tesztekben is).
- Ellenőrzés: tsc 0 hiba, unit 262 + client 59 zöld, dev-szerveren landing
  (self+team mód), pricing, blog, cikk-oldal konzolhiba nélkül.

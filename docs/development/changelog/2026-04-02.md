# Changelog — 2026-04-02

## Team Intelligence redesign

**Profil-alapú friction modell:**
- Az observer-based dynamics edge generálás lecserélve profil-alapú HEXACO gap analízisre
- Súlyozás: C (30%) > A (25%) > H (20%) > E (15%) > X (5%) > O (5%)
- Küszöbök: aligned (<12), complementary (12-22), friction (≥22)
- Minden páronkénti kombináció lefedve (nem csak observer-linked párok)
- UI egyértelműen jelöli: "profil alapú becslés"

**Dimenzió breakdown a dynamics panelben:**
- Kapcsolat kattintásra kinyílik per-dimenzió gap breakdown
- Top 4 dimenzió megjelenítése súrlódási hozzájárulás szerint
- Vizuális gap bar + szöveges értékelés (hasonló / eltérő / nagyon eltérő)
- Kontextus hint per dimenzió (pl. "Eltérő munkaszervezés és határidő-kezelés")

**Team Intelligence evidence és safe state:**
- Centralizált evidence framing rendszer
- Low-data safe state (ha nincs elég kitöltés)
- Summary-only nézet enforcing a deep-dive chart-ok felett

## Manager Cockpit (`/manager`)

**Új route és data layer:**
- `src/app/manager/page.tsx` — csapatfókuszú dashboard
- `src/lib/manager-cockpit.ts` — `getManagerCockpitData()` aggregáció

**Tartalom:**
- Hero szekció — üdvözlés, összesített kitöltöttség, tag/csapat chipek
- Csapatok kártyák — completion bar, dynamics badge-ek, pending meghívók
- Tagok állapot grid — avatar, státusz chip, top 3 dimenzió badge
- Dynamics összefoglaló — 3 metrika kártya + link a részletes térképre
- Utolsó események feed — teszt kitöltés, observer visszajelzés, csatlakozás (max 10, relatív idő)
- Javasolt következő lépés — kontextusfüggő manager akció

**Journey engine wiring:**
- `org-manager` → `/manager` (manager_cockpit) — szétválasztva az admin `/dashboard`-tól
- Új `HomeReason`: `manager_cockpit`
- Journey tesztek frissítve (home.test.ts, journey-contract.smoke.test.ts)

- A jelölt flow (`/hiring/[orgId]`) leválasztva a credit kezelésről
